# Password Lock System Using Verilog HDL

## Project Overview
This project implements a digital password lock system using Verilog HDL. The design models password entry and unlock control using sequential logic and state-based operation.

## Objectives
- Design a digital password lock using Verilog HDL.
- Understand the application of sequential logic and Finite State Machines (FSMs).
- Implement password input handling and unlock control.
- Simulate the design to observe its behavior under different input conditions.

## Tools and Technologies
- **Verilog HDL** — RTL design
- **Icarus Verilog** — Simulation
- **GTKWave** — Waveform visualization

## Functional Description
The system accepts password input and controls an unlock output based on the implemented logic. Clock and reset signals are used to manage the system's operation.

## Project Files
- `lock.v` — Verilog RTL source code.
- `lock_tb.v` — Testbench for simulation and functional verification.
- `password_lock.vcd` — Simulation waveform data, if generated.

## Design and Verification Flow
1. Develop the RTL design using Verilog HDL.
2. Create a testbench to apply inputs and observe outputs.
3. Simulate the design using Icarus Verilog.
4. Inspect signal transitions using GTKWave.

## Learning Outcomes
- Practical exposure to RTL design using Verilog HDL.
- Understanding sequential logic and state-based control.
- Experience with digital circuit simulation and waveform analysis.

## Future Improvements

- Improve reset handling and error conditions.
